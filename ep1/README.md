# 实验一：小型 LLM 预训练与评估

## 实验目的

本实验旨在帮助大家掌握大语言模型（LLM）预训练的基本技术与完整流程：从准备预训练数据出发，完成一个小型 LLM 的预训练与评估，并对训练吞吐效率和模型效果进行实验分析，建立对 LLM 预训练的整体认识。

## 目录说明

本实验项目支持两套显卡生态，对应代码分别位于以下目录：

| 目录 | 显卡生态 | 说明 |
| ---- | -------- | ---- |
| `ascend/` | 华为昇腾（Ascend） | 基于昇腾 910B 加速卡环境的实验代码与文档 |
| `nvidia/` | NVIDIA（CUDA） | 适配 NVIDIA GPU 的实验代码（建设中） |

请根据自己使用的硬件环境进入相应目录，并参考其中的说明文档开展实验。
