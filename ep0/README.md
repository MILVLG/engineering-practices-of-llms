# 实验零：CIFAR10 简单分类网络训练与大模型推理

## 实验目的

本实验旨在帮助大家掌握 PyTorch 和 HuggingFace `transformers` 库的基本使用：通过 CIFAR-10 图像分类任务熟悉数据加载、简单卷积网络搭建、训练与推理流程，并基于 Qwen 模型完成大语言模型推理实验，直观理解 KV-Cache 与常见采样策略。

## 目录说明

本实验项目支持两套显卡生态，对应代码与说明文档分别位于以下目录：

| 目录 | 显卡生态 | 说明 |
| ---- | -------- | ---- |
| `ascend/` | 华为昇腾（Ascend） | 基于昇腾 910B 加速卡环境的实验代码与文档 |
| `nvidia/` | NVIDIA（CUDA） | 适配 NVIDIA GPU（CUDA）的实验代码与文档 |

请根据自己使用的硬件环境进入相应目录，并参考其中的 `README.md` 开展实验。
